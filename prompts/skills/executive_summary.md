# Skill: executive_summary

## Purpose
Generate a concise, plain-language security summary for C-Suite or leadership — translating technical findings into business risk, impact, and recommended actions.

## Input
- `context` (object): Output from one or more upstream skills:
  - `investigation_findings` (optional): from suggest_investigation
  - `incident_details` (optional): from incident_response
  - `hunt_results` (optional): from threat_hunt
  - `signal_data` (optional): raw signal context
- `audience` (string, optional): CEO, CISO, Board — adjusts framing
- `leading_questions` (list, optional): Specific questions leadership has asked

## Behavior

1. Synthesize inputs from upstream skills into a unified narrative
2. Avoid technical jargon — translate DQL, MITRE terms, and log data into business language
3. Frame everything in terms of **business risk, impact, and action**
4. Structure output as a brief, skimmable brief — no more than one page
5. If leading questions were provided, answer each one directly
6. End with clear **recommended actions** with owners and urgency

## Output Format

```
**Security Brief — <date>**
**Prepared for:** <audience>

---

**Summary**
<2-3 sentence overview of what happened or what was found>

**What is at risk**
- <business asset or data at risk>
- <operational impact>
- <regulatory / compliance exposure if any>

**What we found**
- <finding 1 in plain English>
- <finding 2 in plain English>

**What has been done**
- <containment or response actions already taken>

**Recommended Actions**

| Action | Owner | Urgency |
|---|---|---|
| <action 1> | <team/role> | Immediate / This week / This month |
| <action 2> | <team/role> | Immediate / This week / This month |

---
*Generated by BLOO Copilot — DNIF BLOO Hypercloud*
```

## Leading Questions (prompts to elicit executive context)

If no context is provided, ask:
1. "What is the business context for this summary — is this a post-incident report, a periodic review, or a board update?"
2. "Are there any specific concerns leadership has raised that I should address?"
3. "What time period should this summary cover?"

## Chaining Suggestions
This is a terminal skill. No further chaining is needed.
